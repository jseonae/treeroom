# TREE ROOM — 웹사이트 배포용 파일

## 파일 구성

- `index.html` : 사이트 시작 페이지 (압축파일의 최상위에 있어야 합니다)
- `css/style.css` : PC·모바일 디자인 스타일
- `js/app.js` : 장식 편집, 로컬 저장, 화면 인터랙션
- `assets/` : 겨울 방/트리 배경 1종과 오브제 이미지 13종
- `favicon.svg` : 브라우저 탭 아이콘
- `netlify.toml` : Netlify 정적 사이트 배포 설정 (publish = ".")

## Netlify에 수동으로 배포하기

1. [Netlify](https://app.netlify.com/)에 로그인합니다.
2. 기존 프로젝트 **treeroom**이 있으면 해당 프로젝트의 Deploys 화면에서 수동 배포합니다. 새로 만들지 않아도 됩니다.
3. **ZIP 압축을 먼저 풀고**, `index.html`이 바로 들어 있는 `TREE_ROOM_업로드용_완성본` 폴더를 Deploys 화면의 배포 영역에 올립니다. (Netlify API와 달리 일반 드래그 앤 드롭 배포는 폴더 업로드가 가장 확실합니다.)
4. 배포 완료 후 사이트 주소를 직접 열어 트리 배경 및 13종 장식 이미지가 보이는지 확인합니다.

## GitHub로 관리하기

GitHub 저장소 루트에 `index.html`, `css/`, `js/`, `assets/`, `favicon.svg`를 그대로 업로드합니다. Netlify의 해당 프로젝트에서 GitHub 저장소를 연결하면 이후 커밋마다 자동 배포할 수 있습니다.

## 주의 사항

- 현재는 공개 테스트용 정적 웹사이트입니다. 나의 장식과 메시지는 기본적으로 현재 브라우저의 localStorage에 저장됩니다.
- 친구 간 실시간 동기화 및 서버에 보관되는 공용 트리 기능은 아직 제공하지 않습니다.
- 이미지는 모두 프로젝트 내부의 상대 경로로 참조하므로 폴더 구조를 변경하지 마세요.
- Netlify 사이트 주소가 생겼다고 하더라도 다른 기기에서 기존 브라우저의 로컬 장식 상태가 자동으로 나타나지는 않습니다.
